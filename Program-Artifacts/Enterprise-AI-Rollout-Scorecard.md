# Enterprise AI Rollout Scorecard

Sanitized template for moving an AI assistant from pilot to dependable workflow.

## Scorecard

| Dimension | Pilot question | Scale criterion |
|---|---|---|
| User value | Does it remove a recurring task or decision delay? | Repeat use and measurable time/value gain |
| Source quality | Is the answer grounded in current, owned material? | Freshness and ownership thresholds met |
| Answer quality | Is the response correct, complete, and traceable? | Defined evaluation target sustained |
| Action safety | What can the assistant change, and can it be reversed? | Permissions, confirmation, audit, and rollback tested |
| Privacy and access | Does the response respect source permissions? | Access-control tests pass |
| Operations | Who handles failures and feedback? | Support owner, telemetry, and escalation active |
| Economics | Is the value proportionate to usage cost? | Cost per successful outcome within target |

## Rollout stages

1. **Observe:** answer questions from approved sources; no write actions.
2. **Recommend:** propose actions with evidence; a person executes them.
3. **Confirm and act:** execute bounded, reversible actions after explicit approval.
4. **Scale:** expand use cases only after quality, safety, adoption, and economics remain stable.

> Sanitized artifact: illustrative controls only; internal prompts, thresholds, data sources, and access models are omitted.
